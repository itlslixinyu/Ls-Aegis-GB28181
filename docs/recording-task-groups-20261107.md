# 录像任务按设备分组展示

后续分组列表、日期、执行过程、回放和下载的复查及临时查询失败修复见[录像任务复查](recording-task-groups-audit-20261107.md)。本次复查只更新前端，没有重启或调整计划。

## 当前行为

录像任务主列表每个设备分组一行，汇总参与计划或已有计划录像历史的通道数量、录制中、处理中、异常及录像文件数。分组名称和“查看任务”均打开通道明细弹窗，不再在主列表按执行日期累积行。

弹窗默认查询今天，每个通道一行；按执行日期切换历史，支持名称、编号、设备名称模糊查询，每页20路。通道当天中断、重试、恢复仍归并为同一执行记录，执行过程及文件分别用二级弹窗查看，文件保留原任务关联，支持原有回放和下载。没有当天任务显示“当日无任务”，不伪造完成状态。设备录像导出仍独立展示。

数据按照设备当前分组和当前用户的服务端设备范围查询。管理员可显示已删除通道历史；普通用户不能借历史开关扩展访问范围。主汇总不限于原有最近200个通道日，弹窗仅读取指定日期和当前页通道；没有新增或改写库表，没有改动调度逻辑、计划配置或历史记录。

## 实施文件

- `frontend/src/components/RecordingTaskGroups.vue`：分组列表、通道查询、执行过程、文件及导出任务；处理迟到响应、查询提交与轮询、错误及权限失效后的旧数据清理。
- `frontend/src/components/RecordingCenter.vue`：录像任务入口交给独立组件，移除旧列表并停止旧任务轮询。回放页面行为未调整。
- `backend/services/recording-task-groups.mjs`：分组汇总和通道分页查询。
- `backend/services/recordings.mjs`：复用已有按日执行记录聚合函数。
- `backend/services/recording-routes.mjs`、`authorization.mjs`：新增只读接口及 `recording.view` 权限。

接口：`GET /api/v1/recording-task-groups?page=1&pageSize=20`；`GET /api/v1/recording-task-groups/{groupId}/channels?date=YYYY-MM-DD&page=1&pageSize=20&q=...`。可选 `includeDeleted=1` 仅管理员可用。分页、日期及搜索长度均经服务端校验。
