# 用户资料与个人中心完善 · 2026-11-05

## 可用行为

用户管理增加姓名、所属部门、职务、联系电话、电子邮箱、备注、创建时间、最近登录和资料更新时间。列表展示常用字段，详情展示完整资料；管理员可创建用户时填写资料，也可编辑已有资料。提供账号/姓名/部门/电话/邮箱查找和角色筛选，筛选按登录用户保存在当前浏览器会话，刷新后保留。

个人中心分为“基本资料”和“账号安全”。用户可维护本人资料，保存后右上角显示姓名，姓名为空时显示账号。切换栏目保留未保存资料，关闭个人中心或切换登录账号清空表单。本人资料更新同步当前用户管理列表；原改密、重新登录、主题与外观配置保持可用。

资料均可选填；空资料显示“未填写”，缺失历史时间显示“暂无记录”。姓名最多50字符，部门80，职务50，电话32，邮箱254，备注500。电话允许数字、国家区号、空格、括号和短横线，至少3位数字；邮箱检查基本格式。单行字段拒绝控制字符，备注允许换行，资料按纯文本显示。

## 接口与权限

| 接口 | 范围 |
| --- | --- |
| `GET /api/v1/users` | 管理员查看账号与资料列表 |
| `POST /api/v1/users` | 管理员创建账号，可携带 `profile` |
| `GET /api/v1/users/{id}` | 管理员查看完整资料 |
| `PUT /api/v1/users/{id}/profile` | 管理员编辑资料 |
| `GET /api/v1/me` | 读取本人资料和会话 CSRF |
| `PUT /api/v1/me/profile` | 已登录用户仅编辑本人资料 |

资料写接口接收六项字段及 `version`，以完整表单替换，缺省字段为空。禁止借此修改账号、角色、密码、时间或用户归属。写操作须有效登录、CSRF；非管理员不能通过管理接口查看或修改其他用户。

版本冲突返回409，前端保留草稿，可重新读取后保存。编辑弹窗须成功读取目标资料后才能提交；迟到响应不覆盖后打开的账号，也不回填已关闭窗口。审计 `user.profile.update` / `user.profile.self` 只记录操作者和目标，不包含联系方式或密码。响应不回显密码、密码哈希。

部门和职务为展示资料，不参与角色、设备分组授权判定。本轮不提供通过资料编辑调整角色、停用账号或重置他人密码。

## 数据与升级

迁移11新增独立 `user_profiles`，原 `users` 表四列结构保持不变。新账号自动建立资料，删除账号级联清理。历史创建时间仅从真实 `user.create` / `system.setup` 审计回填，最近登录仅从成功 `auth.login` 回填；无法追溯则为空，不把升级时间当作创建时间。新账号创建与成功登录记录真实时间，失败登录不覆盖最近登录。迁移幂等，保留原密码、角色、授权及业务数据。
