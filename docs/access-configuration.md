# 接入配置使用与验收

2026-11-01。补齐已有“接入配置”页面的编辑与保存能力，保持雷铄御警品牌和政企页面风格。

## 页面可配置项

| 分组 | 配置 |
| --- | --- |
| SIP / 国标信令 | 启用状态、监听IPv4、通告IPv4、SIP端口、10位国标域、20位平台编号、心跳超时（秒） |
| 媒体节点 / ZLMediaKit | 管理地址、设备可达的RTP接收IPv4、媒体访问地址、录像路径模板、管理密钥、录像回调凭据 |

填写后点击“保存接入配置”。保存不会自动重启服务或建立新连接，修改后显示“已保存 · 待重启生效”。通过现有服务管理方式重启平台，再检查媒体连接及设备接入。“查看当前生效配置”展示运行中的参数，避免把保存当成生效。

“检查当前媒体连接”使用当前运行配置，不使用尚未重启的草稿。媒体访问地址留空时沿用管理地址；RTP端口由媒体节点实际分配，页面没有提供不会生效的端口范围配置。

监听地址允许`0.0.0.0`；通告与RTP地址应填写设备可达IPv4，不能使用通配地址。国标域修改后，需在重启后逐台重新设置设备接入密码，因为既有Digest凭据不能使用新认证域。

管理密钥与回调凭据不回显。空白保存保留原值；填写替换新值，勾选“清除已有…”才清除。设备接入密码仍在国标设备页面逐台管理。

## 持久化和权限

- 正式运行保存到`data/access-config.json`，与数据库同目录；自定义数据库路径时默认保存到其相邻目录。
- 文件采用临时文件、刷盘、原子重命名保存，只有完整合法配置才替换旧文件。保存项在下次启动时优先于对应环境变量；未保存过则沿用原环境配置。
- 文件包含服务端媒体凭据，应与数据库一起备份，仅服务账户可读；HTTP读取和审计均不返回凭据原文。
- 管理员且CSRF有效才允许保存；只读账号无法读取或写入配置。每次保存记录“保存接入配置”审计，审计不包含配置值或密钥。
- 版本号用于防止旧页面覆盖其他保存；冲突返回409，用户重新读取后再保存。

## 接口

### 在线重启平台

最新真机重启、配置生效、预览自动恢复、新录像分段回放及红色按钮验收见[重启与恢复验收](platform-restart-acceptance.md)。重启后的实时预览会检测平台实例变化并重新点播；窗口关闭或切换码流后不会由迟到响应重建播放器。

操作行增加“重启平台”，管理员确认后应用已保存配置。字段修改须先保存；重启不会代为保存表单。弹窗提示预览、回放和录像中断及录像空档。请求期间禁用重复操作，服务恢复后重新读取配置。说明文字统一 12px，完整单行居中；原编号行边框保持不变。

`POST /api/v1/system/restart` 请求体 `{ "confirm": true }`，仅管理员且有效 CSRF 可调用。返回 202 和当前 `instanceId`；同实例并发调用幂等。审计 `system.restart` 记录受理操作，不记录配置值。`GET /api/v1/system/config` 的 `runtime` 提供实例标识、能否重启和受理状态。浏览器轮询健康接口，只有新实例恢复才提示完成；90 秒未恢复显示未确认完成，避免把受理当作成功。

默认 `npm start` / `node --env-file-if-exists=.env backend/server.mjs` 均支持平台服务重建，进程 PID 和外部 ZLMediaKit 不变。接入配置从持久化文件重载；修改 `.env` 或程序代码仍须重新启动 Node 进程。SIP 配置或端口错误时 HTTP 入口仍可用，修正后可再次重启。直接嵌入服务器且未配置重启回调时按钮禁用，接口明确返回 `RESTART_UNAVAILABLE`。
