# 实时监控布局、缩略图与面板状态

按用户本轮反馈整理，保持雷铄御警品牌和政企蓝，仅完善现有监控功能。参考对象为海康 iVMS-4200 客户端，非摄像机网页登录页。其[官方用户手册](https://www.hikvision.com/content/dam/hikvision/en/support/download/vms/ivms4200-series/software-download/3-13-0-5/iVMS-4200-V3.13.0-User-Manual_20250520.pdf)的索引说明了单格悬浮工具栏与主视图右下角配置入口的区别；本平台按自身功能适配，不宣称完整复刻客户端。

## 当前最终布局

- 资源栏左侧是真实缩略图，桌面144×81，较窄屏128×72。名称、设备名和编号靠左；在线/离线徽标独立放到右侧，整行垂直居中，文字水平居中。在线依据设备与通道均在线，不以有无缩略图代替。
- 缩略图不叠加“最近画面”等文字，采集日期时间在悬停提示中显示。
- 收起按钮位于“通道资源”标题最右侧。收起后保留36px左侧窄栏，展开图标与原按钮保持同一高度，不跳到底部。
- 云台位于资源栏下方，初次默认收起，点击底部栏向上展开；圆形方向盘、停止、速度、变焦沿用原控制逻辑。收起云台或通道栏时卸载控制组件，执行原停止清理逻辑；重新展开不自动发起移动。
- 分屏与全部打开/关闭位于监控墙底部独立操作区；刷新与分页在资源列表底部。
- 单格工具栏默认隐藏，鼠标移到右下角或点击入口展开，键盘可访问，焦点控件保持可操作。**独立关闭按钮始终位于每格右下角**，不藏进工具栏；密集分屏也能直接关闭一路。其他模块播放器关闭位置不变。

## 刷新保持

通道栏及云台展开状态通过既有按账号 sessionStorage 偏好保存，刷新保持。隐藏资源栏时保留云台展开偏好，但实际控制组件已卸载；重新展开后恢复面板状态。

缩略图从真实且正常播放的视频取帧，每路最多15秒一次，等比例缩至192×108以内，不为列表额外点播任何设备。尚未取得真实帧显示“暂无预览”，取帧失败不打断视频。

缩略图在同源 IndexedDB 的 `ls-aegis-thumbnails` 数据库按账号和通道保存，每账号最多64张。刷新时先由服务器按权限取得通道列表，再只恢复这些通道的缓存；迟到读取不能覆盖新检索或较新的帧。缓存采用 ImageData 和 canvas，不放宽页面 CSP、不发送画面到外部服务、不写录像目录。退出或账号切换离开监控页时清理旧账号缓存；浏览器禁用本地存储时回退为当页显示，播放仍可用。

缓存画面是上次采集的缩略图，刷新恢复不代表自动恢复视频点播；离线设备仍按真实设备状态标识。没有真实画面的通道不会生成假缩略图。
