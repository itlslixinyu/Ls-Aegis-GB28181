# 同步回放、拖放与媒体异常恢复（2026-11-07）

本记录取代上一版多通道独立控制的交互说明。本轮不新增业务模块，不修改正式账号授权、设备编码和录像计划，也不重启后端或媒体节点。

## 可用行为

- 回放沿用实时监控布局：居中标题，左侧通道资源和日期，右侧深色画面墙，底部一套控制条。
- 左侧点击通道直接打开；支持从通道资源原生拖拽到任意画面。拖拽采用复制语义，同一通道可放入多个窗口；每个窗口拥有独立标识和固定槽位。替换、关闭一个窗口不会移动其他窗口或重建其播放器。
- 1/4/9/16/25/36分屏、双击放大和Esc还原保留。缩小布局仅关闭超出新布局的槽位。
- 全部画面共用一个24小时时间轴，以及播放、暂停、倍速、静音控制。平台录像按同一北京时间定位，不再让各路自行跳过空档；无录像时显示明确空档，并清除旧画面。
- 时间轴始终可选择，尚未完成索引也能记住用户时间并开始等待该时刻的数据，不必等所有文件索引结束；已加载分段数量等过程文字从主区隐藏。覆盖颜色仍只来自实际确认的文件时长，不伪造录像范围。
- 录像文件和下载移到左侧“录像文件”弹窗，不再挤占画面高度。
- 画面区根据当前可视高度计算，通道资源单独滚动。清理全局section的居中外边距、宽度限制和默认内边距，避免宽屏空窗口缩成窄条、四画面撑出屏幕。

## 同步与资源

平台录像以统一单调时钟为基准，各视频校正至共同的日内时间，偏差超过0.65秒时重新定位，跨分段按真实覆盖切换。设备录像转换为片段内秒偏移，通过已有SIP回放控制执行定位、倍速、暂停和恢复；控制失败在对应窗口提示。设备录像切换分段使用检索到的真实条目，结束后再次定位会申请新回放会话。同步为浏览器播放器级对齐，不能保证不同厂商设备的帧级同步。

重复通道的窗口标识与设备通道编号、录像条目编号分离，服务端授权仍使用真实条目及通道，关闭仅释放本窗口资源。所有播放器继续独立续租和超时回收，不影响录像计划引用。

录像元数据探测增加全局4个并发名额，排队可取消，卸载或重新索引释放名额，避免36个窗口同时大量读取文件元数据，争抢同源媒体连接。

## 媒体错误

此前正式实时监控出现过通用“视频加载失败”提示，重开恢复，原始错误没有被旧版本保留，不能认定根因已经定位。

新版本记录播放器错误类型、细节及时间（按本窗口账号作用域存于sessionStorage），在设置中展示最近诊断。瞬时网络、解码或缓冲错误先读取权威媒体会话；会话仍ready且非不支持的编码时，最多重建两次本窗口播放器，复用当前租约，不重复点播。稳定播放一分钟后重置重试次数。权限拒绝、已结束的会话不盲目重试；设备回放completed视为正常结束。旧播放器和旧代次的迟到错误不能覆盖新连接。
