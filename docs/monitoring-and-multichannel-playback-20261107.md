# 实时监控与多通道回放调整（2026-11-07）

## 本轮结果

实时监控标题居中，删除标题下说明。通道栏收起后不再留下窄栏，展开入口移到页面标题左侧的“通道资源”按钮。分屏与全部打开、全部关闭集中在右下角，删除原右侧双击提示。通道缩略图与在线状态继续保留，云台仍位于资源栏下方。

刷新按账号及浏览器标签页保存布局、活动窗口和各槽位通道编号；最多36路。恢复时并发最多4个请求，从服务端重新查询通道及权限，离线、已删除、无权或读取失败的通道不发起点播并显示汇总提示。全部关闭、手动选择和分屏操作会取消迟到的恢复结果。只保存编号，不缓存设备密码、媒体密钥或播放地址。

各监控窗口保存自己的观看租约标识和主/子码流选择。刷新先通过服务端状态和续租校验复用有效租约，过期则释放并重新申请，避免36路刷新形成72个观看者。正常关闭仅释放本窗口租约；浏览器异常退出仍由服务端租约超时回收。双击放大状态不保存，刷新恢复原分屏。

平台录像和设备录像共用新的多画面容器，支持1/4/9/16/25/36布局、双击放大、Esc还原、单路关闭及全部关闭。缩小布局会关闭超出窗口的回放；单路关闭时其他播放器实例保持。平台录像选择通道及日期后“加入回放”，可加入多个通道，每路独立24小时时间轴并自动接续原分段。日期同时应用于当前平台回放窗口。设备录像逐通道检索并点击“回放”，保留其他通道；同通道新片段替换本通道窗口。所有窗口默认静音，仍由原有服务端鉴权。

录像任务的“查看过程·N次”和“N个文件”改为原生模态弹窗，查看不再撑高表格。执行过程按开始、结束、状态及原因分列，文件按日期、名称和操作分列；弹窗随任务轮询更新，不保存过期文件快照。文件内可继续打开播放弹窗及下载，关闭播放后回到文件列表。

## 限制与部署

此次只更新前端构建，不重启后端或媒体节点，不修改正式设备编码、账号授权和录像计划。不是帧级同步回放；各通道独立播放、暂停和定位。尚无真实多通道录像机可验证设备端并行回放能力，也未进行36路真实解码性能测试。原生播放器的服务端权限、续租和资源回收实现继续复用。
