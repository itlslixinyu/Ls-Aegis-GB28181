# 现有功能全流程检查与修复

日期：2026-11-01。品牌仍为雷铄御警 / Ls-Aegis；保持现有政企风格，不新增业务模块、业务接口或数据库迁移。

## 环境和方法

按接入配置、账号与分组、设备、视频与录像、告警与位置、级联和审计的使用顺序，浏览器巡检现有14个页面。写入、边界值、失败和权限测试使用临时数据库及明确标注“[测试]”的记录。隔离 UI 绑定 `127.0.0.1:3001`，SIP关闭、媒体未配置；正式平台 `localhost:3000` 不写测试数据。

后端直接调用接口验证请求类型、边界、业务冲突、CSRF、角色及分组权限；浏览器检查真实表单约束、提示、按钮状态和修正后的重试。没有通过浏览器新建或重置密码、提交删除或扩大实际资源权限。用户创建、凭据和删除等由隔离HTTP回归验证。

## 发现并修复

| 问题 | 修复与证据 |
| --- | --- |
| 正常登录也累计失败限流 | 仅在格式或凭据错误时增加计数；连续12次正常登录通过，10次失败后仍拒绝继续尝试 |
| 登录/用户账号的pattern不兼容浏览器Unicode v模式 | 转义连字符并补充长度及格式提示；浏览器非法账号`a!`的patternMismatch为true，`qa-reader`有效；增加前端回归 |
| 网络中断直接显示英文fetch错误 | 统一中文连接提示，写操作要求刷新确认结果，不自动重发；请求测试验证只发送一次 |
| CSRF失效后仍停在业务页，重新登录路径不清晰 | 当前会话CSRF拒绝返回登录并显示原因；普通403及旧会话响应不注销新登录，登录成功清除提示；浏览器与回归均通过 |
| 不存在的级联共享配置返回500 | 改为404和“上级平台不存在”，保留管理员权限检查 |
| 非法录像计划channelId暴露SQLite绑定错误 | 在访问数据库前校验字符串类型，统一提示选择有效通道；覆盖缺失、null、数字、对象和数组 |
| 录像/订阅列表读取失败被当成无数据，错误恢复后仍残留 | 独立保存列表错误，失败不显示正常空态；成功读取清除对应错误；隔离503与恢复实测 |
| 地图轮询清除位置保存错误 | 列表错误与表单消息分开；慢请求失败经过自动刷新后仍显示保存错误，修正后重试成功 |
| 保存过程中可取消/按Escape关闭并重开，导致结果归属混乱 | 写入弹窗提交期间阻止原生cancel并禁用取消按钮；保留只读通道和共享读取弹窗的原有关闭路径。8秒慢请求实测保存、取消、关闭禁用，Escape不关闭；失败后恢复 |
| 录像确认弹窗沿用之前操作错误 | 打开确认时清空旧操作消息，列表轮询错误不再覆盖操作消息 |

主要修改：`backend/server.mjs`、`backend/services/feature-routes.mjs`、`backend/services/recordings.mjs`、`frontend/src/api.ts`、`frontend/src/App.vue`及现有业务组件。新增 `backend/workflow-acceptance.test.mjs`，扩展 `backend/frontend-api.test.mjs`；故障注入仅存在于 `scripts/ui-fixture.mjs` 的显式测试环境中，没有添加正式故障接口。

## 权限与异常恢复

- 只读账号在浏览器巡检其可见8个页面，仅见一个授权设备/通道及相应告警、订阅、地图和轨迹；无管理员菜单、设备编辑、订阅设置、告警处置或地图写入入口，其他分组及新建测试设备不可见。
- 绕过页面直接调用用户、分组、授权、设备、凭据、传输、目录同步、位置、订阅、录像计划、级联、云台与媒体检查等21种管理写操作，服务端全部拒绝只读用户。
- 未登录、无效CSRF、跨组设备/通道/轨迹读取、撤销分组授权后的再次访问和注销后的旧会话均已验证。撤权后相关列表返回空，原设备详情拒绝访问。
- 刻意注入的400/403/503仅用于验证异常分支，已清除注入文件；测试服务和标签已关闭。没有把故障响应记为正常空数据或业务成功。
- 桌面检查完整流程；390×844窄屏检查会话失效、重新登录与只读资源。地图页内容宽度与视口内容宽度均375px，无整页横向溢出。临时视口已恢复。
