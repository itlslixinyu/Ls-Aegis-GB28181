# 雷铄御警 Ls-Aegis 界面规范

2026-11-01。平台中文名统一为“雷铄御警”，英文名为“Ls-Aegis”。页面标题、登录页、工作台、默认级联设备名称、对外厂商名称及地图请求标识同步更名；历史截图和验收记录保留原有事实。

## 设计方向

按用户提到的[Arco Design](https://arco.design/)方向实现浅色企业后台：白色导航与内容面板、浅灰工作区、蓝色主操作、清晰的文字层级、统一的表格与表单。Arco由字节团队推出，阿里/蚂蚁系为Ant Design；本次按Arco方向落地，没有引入新的UI运行依赖或改写业务API。

基础主题在`frontend/theme.css`，业务布局在`frontend/style.css`，统一图标在`frontend/src/components/AppIcon.vue`，盾形闪电标识在`BrandMark.vue`。后续新增和修改页面复用这些基础组件及变量，避免另起一套字号、按钮或边框规则。

## 布局与交互

菜单已进一步参照用户OA平台改为一级分组折叠、二级功能缩进，并增加完整面包屑、菜单搜索和已打开页面页签。当前结构、权限及验证见[导航参考与改进](navigation-reference.md)；下方原改版截图保留作历史记录。

- 14项菜单保留原来的使用顺序，分为基础管理、视频业务、事件与位置、平台运维；viewer继续隐藏管理员入口。
- 桌面使用224px侧栏，可收起至72px；收起后保留可访问名称与提示。顶部包含当前页面、真实账号和退出入口。
- 手机使用独立抽屉导航；选中菜单、点击遮罩或Escape可关闭。关闭的菜单隐藏于可访问性树，打开及关闭时调整焦点。
- 登录页使用左右分栏与品牌示意图，手机仅保留登录内容；保留原初始化、登录、错误及自动填充行为。
- 设备页统计卡使用真实接口数据；设备表格在自身容器内横向滚动。列表、表单、禁用状态、空态和错误反馈使用统一样式。
- 监控视频区域保留暗色以适合观看，周边管理界面采用浅色。没有设备或媒体时继续显示实际缺少的条件，不填充演示视频、告警或轨迹。
- 兼容减少动态效果偏好；图标按钮提供可访问名称；原生弹窗保留焦点及键盘行为。

## 实际验证

类型检查、构建和现有69项本地回归通过。浏览器使用实际admin巡检14个页面，没有页面加载错误或控制台error；检查1440px桌面收起/展开导航、设备新增弹窗及取消、390px手机布局及末尾菜单入口。最终构建另验证菜单打开焦点进入第一个导航项，Escape关闭后焦点返回按钮，关闭的菜单不出现在可访问性树。

桌面与手机登录页已检查；使用原有admin真实退出、重新登录成功。输入框及截图未保存账号密码明文，账户凭据没有改动。临时视口已恢复，验收标签已关闭，用户原有标签保留。

正式服务在备份`backups/pre-ls-aegis-1793509369525/data`后更新，首页、JS和CSS资源均200。与更新前备份比对25张非会话/审计表完全一致，包含原账号及设备；SQLite完整性ok、外键错误0。登录会话和审计仅按实际退出/登录变化。SIP依旧未启用，媒体未配置。

本次未写入设备/分组/录像等业务数据，没有配置或连接真实设备、媒体或上级平台。视觉验收不能代替真实GB28181联调。
