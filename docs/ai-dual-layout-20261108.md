# AI 双画面与合并记录第一版（2026-11-08）

按用户本轮布局要求修改，完成后停止继续调整，等用户查看效果。

## 当前可用行为

- 画面分析左侧保留来源选择及通道列表，参照回放资源栏的宽度和密度。
- 右侧改为两格：原始画面、分析结果。结果格显示实际中文描述和标签，不伪造检测框或第二路视频。
- 分析要求、模型选择、开始分析和配置模型统一在两格下方。
- 模型可选择本地千问或大模型；上传和通道抓拍均按所选方式发起原有分析接口。未接入的大模型显示提示并禁用提交。
- 分析记录页包含画面分析记录、录像检索记录两张卡片。录像检索页的分析记录按钮进入同一页，不再单独维护一份历史表格。
- 从录像检索记录点击查看结果，按账号保存查询标识并进入原检索结果，不创建新检索任务。

## 文件

- frontend/src/components/AiAnalyses.vue：双格与下方表单，合并记录页。
- frontend/src/components/AiHistoryRecords.vue：由前端设计 Agent 实现的检索记录卡片，包含加载、重试、迟到响应和卸载保护。
- frontend/src/components/AiSearch.vue：统一记录入口，移除重复历史列表逻辑。
- frontend/src/App.vue：连接记录导航事件。
- backend/frontend-components.test.mjs、backend/ai.test.mjs：迁移列表回归并补充导航及本地通道选择验证。
