# 取消8画面与32条分页验收

日期：2026-11-03，版本v0.7.1。只调整现有列表与预览布局。

## 已实现

- 取消8画面，保留1、4、9、16、25、36六档。
- 设备列表由每页20条改为32条；设备通道弹窗和实时监控通道列表使用服务端32条分页，显示总数、当前页/总页、上一页和下一页。
- 监控通道搜索覆盖全部授权通道，不再只搜索最先载入的500路；翻页不卸载当前播放窗口。其他页面发起的预览使用精确通道查询，第33路以后的通道同样可定位。
- 翻页请求失败可重试；迟到成功/失败不能覆盖新页或已关闭弹窗；通道数减少时自动回到有效页。父设备离线时通道弹窗禁用预览。
- 两个通道接口返回`items/total/page/pageSize`，权限同时约束计数、分页结果和精确通道查询。旧调用方不传分页参数时保留原有数量限制；本轮未改其他业务页面的通道选择器。

独立临时库与服务`127.0.0.1:3002`，所有样例标记“模拟”，未写入正式库。浏览器实际验证33台设备为32＋1；65路通道为32＋32＋1，第33路与第65路可达、末页下一页禁用；监控搜索“通道65”返回一条并重置为第一页，布局按钮仅六档。该模拟不证明真实65路录像机或并发视频兼容性。
