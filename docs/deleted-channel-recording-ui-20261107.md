# 已删除通道的录像历史显示修复

用户报告的`af8f3b53-5fbc-4ffd-a058-1c8834c94e99:34020000001310000002`来自历史录像任务/执行记录，并非仍在运行的计划。只读检查发现：当前仅有海康有效启用计划；已删除通道的任务均为cancelled、failed、interrupted或succeeded，无在录任务。

原因：计划删除后任务外键置空，通道删除后名称关联为空，但历史文件按保留期保留。前端此前把所有历史任务直接展示，并用内部channelId补名称，造成“计划录制＋内部UUID”看起来像未清除的有效计划。

修复：

- 执行记录、录像任务、回放通道及文件列表默认隐藏已删除通道的历史记录，统计同步按可见记录计算。
- 提供“显示已删除通道历史录像”入口，选择按账号保留；这是查看历史的显示开关，不创建或恢复计划。
- 历史通道显示“通道已删除＋20位国标编号”，无法恢复历史名称时不编造名称，也不直接显示内部UUID。失去计划名称的已删除通道任务显示“历史计划录像”。
- 取消历史显示时，清理已失效的通道选择；历史文件仍使用原jobId访问，不删除文件或改变权限。

文件：`frontend/src/components/RecordingCenter.vue`、`frontend/video-business.css`、`backend/frontend-components.test.mjs`。

验证：54项相关测试、类型检查及构建通过。正式浏览器默认显示3个海康通道日记录；开启历史后显示7行，删除通道明确标注且无内部UUID名称；关闭后恢复3行。录像计划只显示1条有效海康计划，仍在录制。回放通道默认仅有现存海康通道。未修改正式计划、授权、录像数据，未重启平台。

证据：`.tmp/deleted-channel-ui-tests.log`、`.tmp/deleted-channel-plans.png`。本轮是历史显示修复，不将旧失败记录描述为新的录制任务。
