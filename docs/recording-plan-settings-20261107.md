# 录像计划时间、保留和分段设置

按用户要求仅调整计划参数及展示，执行周期、启停状态、任务逻辑等保持。

- 新建计划默认勾选“全天录制（00:00—24:00）”。沿用现有后端约定，以startTime=endTime=00:00保存完整24小时，不再把23:59当作全天。取消勾选可填写原有自定义开始/结束时间。
- 保留时间按整数天设置，范围1—365；不是播放器的可播放时长。
- 新建计划分段提供1、3、5、10、15、20分钟。已有其他合法分段值（例如60分钟）以“现有值”保留，编辑时不隐式改写。
- 列表将录制时段、保留时间、文件分段、状态分别展示；全天明确显示00:00—24:00，启用/停用仍是独立状态。
- 已有计划按原值读取。勾选全天只在保存时转换，不因打开/取消表单而修改原数据。
