# 2026-11-05 平台重启与真机恢复验收

## 修改

- `frontend/src/components/AccessConfiguration.vue`：操作行的“重启平台”和弹窗“确认重启”均采用红色危险操作样式，保留权限、确认与重连提示。
- `frontend/src/components/LivePlayer.vue`、`frontend/src/platform-recovery.ts`：修复平台重启后原预览窗口停在加载失败的问题。为观看记录平台实例，断流后仅在确认平台实例更换且服务健康时重新点播；保留主/子码流、静音、音量和比例。多窗口共享并发健康请求，观看者仍独立管理。
- 普通设备故障不自动反复点播；权限失效与设备录像回放不自动重建。窗口关闭、切换码流或离开页面取消等待，迟到点播仅回收自己的观看者。恢复检测最长 90 秒，平台启动异常不会误报恢复成功。
- `backend/platform-recovery.test.mjs`、`backend/frontend-components.test.mjs`：新增 6 项恢复检测测试和 3 项播放器恢复测试，并调整组件测试对现有筛选持久化依赖和异步准备顺序的适配。

## 实际重启

本机 `http://localhost:3000`，通过隔离 Chrome 实际点击正式平台按钮。使用既有管理员登录，未修改任何账号或密码。

1. 重启前，大华主码流实际解码为 2560×1440，存在一个正在录制的计划任务。
2. 临时把心跳超时从 180 秒保存为 181 秒。重启前当前生效值仍为 180 秒；点击红色按钮并确认后，新实例在约 2.18 秒恢复，当前生效值成为 181 秒、待重启标记消失。首次实测发现旧预览窗口未自动重新点播，随后修复。
3. 刷新测试预览页加载修复版本，恢复心跳为原值 180 秒并保存，再通过按钮重启。约 2.15 秒后新实例恢复，当前值为 180000 毫秒且 `restartRequired=false`。原大华预览窗口自动重新点播并解码出画面；前台复核时播放时间从 360.98 增至 365.99 秒、解码帧数从 4748 增至 4873。
4. 原启用录像计划自动接续，新任务 `de4984f9-24ce-4689-9b03-072630e5c76b` 为 `recording`，未手动停用或重新启用计划。等待其原定 300 秒分段，生成 `2026-11-05-14-31-46-0.mp4`。
5. 在“录像回放 → 平台录像”实际打开上述新分段。最终前台复核为 2560×1440，播放 7.06 秒、183 帧、音频解码字节 59520，时间与帧数持续增加。
6. 再次前台复核实时预览，2560×1440、`readyState=4`、未暂停，播放 12.10 秒、308 帧、音频解码字节 108931。正式配置已经恢复，无待重启修改；录像继续运行。关闭测试预览，释放测试观看者。

多标签自动化在后台视频暂停时不能按前台播放状态断言。本次修正截图和采样先置前的测试步骤，额外执行完整的前台回放、实时播放、配置、录像任务及按钮校验；未为测试焦点问题重复重启正式平台。最终独立验证输出保留在本机 `.tmp/restart-post-verification-result.json`。

## 目标与边界

实测设备为大华 DH-IPC-HFW1433M-A-IL2，既有接入档案固件 2.860.0000000.40.R、build2026-05-15，GB/T28181-2016、UDP。本轮未重新读取固件，也未修改摄像机编码、SIP 地址或端口、媒体节点及录像计划参数。媒体节点只读回查仍接收 H265 2560×1440 与 PCMA（G.711A）8 kHz；网页实际解码为 `hvc1.1.6.L150` 和 `mp4a.40.2`。

自动恢复逻辑按平台实例和通道实现，不包含品牌、设备编号或型号判断。本轮真机恢复验收覆盖上述大华和现有录像计划，未新增海康或 NVR 的重启验收。重启存在预览中断和录像空档；计划按已有收尾与重试间隔恢复，不能视为无缝录像。
