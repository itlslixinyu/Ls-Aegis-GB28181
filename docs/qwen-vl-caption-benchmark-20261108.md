## 模型和运行方式

模型来自Qwen官方仓库：https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct-GGUF ，固定提交52d6c8ffea26cc873ac5ad116f8631268d7eb503，Apache-2.0。主模型Q4_K_M为1,107,409,952字节，视觉组件Q8_0为445,053,216字节，总计约1.55GB。逐文件SHA256和来源保存在私有data/ai-models/qwen3-vl-2b-q4/manifest.json；下载时已按官方LFS哈希校验。

运行库使用ggml-org/llama.cpp官方b12189 Windows CPU x64压缩包，固定SHA256校验，解压至data/ai-tools/llama-b12189/bin。没有安装系统服务或新监听端口。参考多模态说明：https://raw.githubusercontent.com/ggml-org/llama.cpp/b12189/tools/mtmd/README.md 。本轮使用独立llama-mtmd-cli测试工具，不以该实验CLI作为已接入的生产服务。

复现：

```powershell
node scripts/setup-qwen-vl-local.mjs
Expand-Archive -LiteralPath data/ai-tools/llama-b12189/runtime.zip -DestinationPath data/ai-tools/llama-b12189/bin -Force
./scripts/benchmark-qwen-vl-local.ps1 -SampleCount 3
```

测试图片只从既有alarm_snapshots读取并缩小到最长边448像素，位于私有.tmp/qwen-caption-inputs。没有下载外部测试图片，没有上传告警图片到外部服务，也没有向摄像机发送新的点播或控制命令。

## 实测

本机i7-8700、6核12线程、16GiB内存、无独立显卡。每次一个独立CPU进程，单线程、固定一个逻辑处理器、低于普通优先级，禁用GPU；上下文1024，图片最多256 token，输出最多160 token，temperature=0。每张图都重新启动模型进程，耗时包含模型加载、图片编码、提示处理和生成；第二、三次启动可能受系统文件缓存影响，不是常驻模型热请求测试。

平均32.37秒。最高工作集约2.29GiB，不能与私有内存直接相加。系统可用物理内存采样最低约2039MiB；这些是特定场景测量，不是所有负载下的上限。首次监测脚本误用32位整型导致计数溢出，已及时停止该测试进程，改为64位计数并增加异常退出清理；该中断试跑不计入上表。

样本1原始描述：

## 预览和录像保护

测试前后源流ID、观看租约ID、计划录像任务ID及状态完全一致；源流保持ready、录像recording、无错误。基线到测试结束，已有录像文件数316增至318。测试过程中70次健康请求全部正常且实例编号保持一致，最高响应约32.55ms；没有重启正式服务。测试进程已退出，无模型后台常驻。

本轮未打开新的实时预览或测量浏览器逐帧卡顿，不能把健康接口正常和会话未变描述为任何负载下的零影响。单张模型测试启动前至少要求2600MiB可用内存；运行期间低于768MiB、工作集超过2800MiB、300秒超时或平台健康异常会终止测试进程；不终止平台或媒体进程。
