## 修改

`backend/ai/qwen-runner.mjs`采用新版描述提示词：先区分人物与背景，只有与可见人体明确相连的衣物才描述为穿着，不完整人物如实写局部；无法确认的褶皱背景采用悬挂布料等保守说法。仍忽略水印与时间，不要求所有图片包含特定物体。

新增保守标签清洗：用中文分词核对标签中的词是否在描述中出现，删除描述未支持的额外标签；过滤“3至6个搜索关键词”等指令残留。该规则只检查描述与标签一致性，不是对图像事实的二次识别，可能减少同义词标签；搜索仍会匹配完整描述。没有将“衣物”硬替换为“窗帘”，也没有覆盖旧分析记录。

新配置最长边384像素、最多192图像token、最多112输出token；旧版分别448/256/160。最初验证的是单线程p3g1，用户随后询问多线程与5秒目标，补充了2/4线程测试，并最终选择2线程、低优先级、限定CPU范围，不启用GPU或增加任务并发，不常驻模型。模型权重、Q8视觉投影和llama.cpp运行库未变。当前结果模型版本为`local-qwen3-vl-2b-q4-k-m:q8-vision:384:p3g1:t2`，保留单线程、4线程及baseline配置用于对比。诊断原始输出仅在测试显式开启，不向网页增加接口。

现有全局单任务、每通道至少120秒、两次启动至少60秒、排队15分钟、内存保护、权限复核和取消回收规则均保留。多线程采用更保守的媒体负载门槛：2项活动录像或4个有效观看租约时等待；运行中达到门槛则取消自有模型并延后重试。观看租约统计包含录像等已有内部引用，不等同于浏览器窗口数量。
