# 智能检索工作区合并（2026-11-08）

## 页面结构

智能检索一级菜单下仅保留：

| 二级菜单 | 用途 |
| --- | --- |
| 录像检索 | 通道与时间范围、文字/参考图组合检索；页内保留图片分析、已有画面匹配入口 |
| 分析记录 | 两张列表分别展示画面分析记录与录像检索任务，可打开详情、取消待处理任务、恢复检索结果、定位原录像 |
| 模型配置 | 原有本地/大模型与索引配置，未改后台逻辑 |

原“画面分析”不再占用独立二级菜单。旧 #page=aiAnalysis 和已保存页签映射到 #page=aiSearch；新增 #page=aiRecords。记录的采集/查询时间、关键词、状态与任务数据仍由原接口提供；未合并或删除后台记录。

主工作区保留左侧通道资源、录像预览、候选结果与下方时间/描述/参考图。文字与图片可单独或组合查录像；单张图片分析为页内模式，隐藏不适用的通道栏。已有分析画面检索仍可从页内进入，固定匹配已保存画面，避免重复暴露另一套录像检索页。

## 状态与权限

页内模式和时间使用按账号的会话偏好；在同一工作页切换图片分析再切回，保留已返回的录像候选。重新打开录像检索记录恢复原时间、描述、通道与结果，只读取原任务，不自动重新提交。图片上传不切走已选通道/时间。文件选择内容本身不写入浏览器持久存储。

记录页与工作页分别挂载，仅记录页拉取完整画面记录列表，工作页只读取模型状态和当前任务。切页停止客户端轮询和录像播放器，后台已受理任务仍可在记录页查看。两个页面均保持 ai.view 菜单权限；发起分析、录像读取和模型配置仍依赖原权限/服务端校验，无角色授权变更。
