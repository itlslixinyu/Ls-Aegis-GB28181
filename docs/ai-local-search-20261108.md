# 本地低算力录像检索：实现与验收

日期：2026-11-08。状态：代码、本机模型基准和隔离环境真实录像检索已验证；正式 3000 服务未重启、未切换。本轮不改变摄像机、预览链路或录像计划。正式数据库仍为迁移15；迁移16在下一次更新启动时应用。

主要变更：`backend/ai/local-model.mjs` / `local-worker.mjs`负责独立本地推理，`feature-cache.mjs`负责缓存，`history-search.mjs`负责授权查询和候选筛选；`service.mjs`接入本地参考图，`archive-reader.mjs`校验源文件版本，`settings.mjs`区分本地与云端密钥需求。`AiSearch.vue`提供复核开关与缓存指标，`AiModels.vue`同步配置说明。安装、基准和迁移分别在 `scripts/setup-ai-local.mjs`、`scripts/benchmark-ai-local.mjs` 和迁移16中。

## 已实现的行为

历史检索改为按需查询：限定授权通道和时间范围，最多选12个已收尾文件、每个文件抽取起点及中点，共最多24帧。本地量化 CLIP ViT-B/32 计算512维图文向量并排序，只有前4张候选可交给 DeepSeek，一次查询最多一次外部复核。不是逐帧、全量、无遗漏的检索；不把向量相似度当命中概率。

关闭“使用DeepSeek复核少量候选”后，完全在本地返回相似候选，并显式标注“尚未复核”。历史以图搜图的参考图片仅在后台正规解码和保存，不先发给外部模型；原手动画面分析、已有分析画面检索仍保留。

中文文字初筛使用本地常见物体、颜色、场景词库转为英语 CLIP 提示词，不额外调用 DeepSeek 翻译。未知中文条件直接提示不支持，不能宣称任意中文自然语言均可识别；可使用英文描述。这一版本没有目标检测器、物体框、人员身份识别或设备端智能事件接入。

## 模型与资源隔离

- `@huggingface/transformers` 固定4.3.2；`Xenova/clip-vit-base-patch32` 固定提交 `6b7c523703ae26e39be4b03774966f8571c7f523`，q8，224像素输入。模型许可MIT，来源和逐文件SHA256见 `scripts/ai-model-manifest.json`；没有使用受研究许可限制的MobileCLIP权重。
- `npm run ai:setup` 显式安装到 `data/ai-models/clip-vit-base-patch32`，校验固定SHA256。可通过 `AI_LOCAL_MODEL_DIR` 指定目录。在线请求禁止联网下载模型。
- 模型运行在独立子进程，单CPU线程，低于普通优先级；一次只处理一项推理，90秒超时、取消时终止，空闲60秒释放模型。没有在HTTP主线程加载ONNX模型。
- 已有保护：正常AI分析任务优先；4项及以上活动录像或9个及以上观看租约时，历史检索等待。新增内存门槛：模型未启动时预留384 MiB启动空间并保留1 GiB余量；模型已加载时要求至少1 GiB可用。每次推理后让出100毫秒。不能保证所有负载下完全无影响，达到门槛会等待并允许取消。
- 只读取已收尾文件，FFmpeg单线程、低优先级；不点播实时通道，不关闭或复用录像的观看租约。

## 缓存、权限和迁移

迁移脚本 `scripts/migrations/016-ai-local-cache.sql` 新增录像时长、帧/向量、少量候选复核缓存和任务指标列，不改计划、执行任务及原录像文件。

帧缓存键含录像文件ID、源文件版本、采样偏移、模型提交及量化版本。远程媒体使用HEAD返回的长度和ETag/修改时间；无法验证版本时不复用。本机ZLMediaKit的HEAD返回长度0且无版本头，已增加显式本地目录映射：`AI_ARCHIVE_LOCAL_ROOT=D:/监控管理软件/data/media/recordings`，`AI_ARCHIVE_LOCAL_URL_PREFIX=/record/`，仅对回环媒体地址使用实际文件的大小、inode、纳秒修改/变更时间校验，并拒绝目录逃逸。该配置已写入本机.env，仅在更新后的服务读取时生效；没有改变媒体节点自身配置。缓存保持正规化JPEG原字节及尺寸/哈希，不再二次压缩，以免相同候选被误判为新图片重复复核。文件变化会重新解码和推理；删除录像数据库条目会通过外键删除帧和时长缓存。权限在每次查询、读取和发布结果时复核，缓存不提供单独的公开访问接口。

帧缓存最多1000项/128 MiB；时长最多10000项；复核缓存按账号、查询、实际图片SHA256和DeepSeek模型隔离，最多500项。定时清理到期项。文字查询向量最多100项，仅保留在当前工作实例内；帧、时长和复核缓存持久化，可跨平台重启复用。复核命中缓存时不重复计费，界面展示实际外部调用次数。

## 本机实测

机器：Intel i7-8700，6核12线程，16 GiB内存，Intel UHD630。本轮使用CPU，没有宣称使用GPU/NPU或验证64路解码能力。

用既有海康录像提取的1280×720 JPEG测试真实q8模型，复现实验：

```powershell
npm run ai:setup
node scripts/benchmark-ai-local.mjs .tmp/ai-archive-read-probe.jpg .tmp/ai-local-benchmark-final.json
```

实测首次画面推理含加载1314毫秒；5次已加载推理129/115/136/122/153毫秒；首次文字含加载837毫秒；工作进程峰值335 MiB。相同图像向量余弦为1。这里只证明模型可运行与耗时，不等于有标注数据的准确率、召回率或完整录像查询耗时。

样本沿用既有海康 DS-IPC-T12HV3-LA、V5.7.20 build241205、GB/T28181-2022 的历史录像。没有发送新的设备控制指令，没有改变H.265+G.711A接入约定；本轮不构成新固件或其他品牌的协议兼容性验证。

已通过45项相关后端测试及3项前端AI交互测试，覆盖缓存复用与失效、文件删除、权限撤销、取消、无密钥本地图片检索、最多4张/1次外部复核、录像分组及媒体回归。类型检查及隔离前端构建通过。

## 后续上线与未验证项

为遵守不中断预览和录像的要求，本轮保留正式服务和dist原样，不自动重启。部署时需先备份库、更新前端并在维护窗口重启后端，确认迁移16、真实预览、同日录像接续及完整检索，再报告正式生效。低内存状态下不强行放开保护。真实缓存冷热检索已通过；本轮没有重新验证录像播放器的文件内定位、下载以及真实多通道NVR并行取流。

设备智能元数据、运动事件预筛选、自动硬件解码选择、目标检测器、向量近邻数据库、64路真实NVR性能和有标注检索质量评测均未实施或未验证。当前小规模向量候选直接余弦排序，避免引入额外服务和常驻GPU模型。
