## 本轮关闭的问题

| 问题 | 修复及验证 |
| --- | --- |
| 退出登录后MP4仍继续传输 | 下载连接绑定登录token；HTTP验证仅中断本登录的传输，同账号另一登录保留；撤权原用例继续通过 |
| 取消完成后迟到active通知恢复取消状态 | 已停止对话仅记录迟到序号，不重新激活或写历史点；终止通知及截止清理仍生效 |
| 请求挂起/非JSON错误提示不清楚 | 业务API30秒Abort截止，错误格式统一；写操作超时提示先刷新确认结果，不自动重发 |
| 旧账号响应污染新登录 | 请求绑定会话代次，旧成功、401及无效JSON均不能覆盖/注销新会话；6项前端请求测试 |
| 级联共享读取失败可保存空列表 | 未完整读取配置禁止保存；浏览器分别模拟503与正常读取，验证按钮禁用/可用 |
| 录像计划执行记录混入设备导出 | 数据库先按scheduled筛选再LIMIT 200；HTTP验证两类型及非法参数；页面确认下载不再出现在计划记录 |
| 监控刷新反复覆盖用户选择 | 初始通道仅应用一次，刷新保留仍在线且授权的已选通道，失效通道清空；静态/类型检查和离线界面复查 |
| 播放器自动播放受阻没有恢复入口 | 显示实际可点击的播放按钮；控制晚于页面退出不重建播放器，倍速失败恢复已接受值；类型检查通过，真实浏览器解码仍待真机 |
| 设备统计/分组列表/告警详情迟到响应覆盖新状态 | 请求序号和卸载保护；告警关闭失效读取，分组授权重开不沿用旧读取结果；类型及正常页面复查 |
| 非法账号或数字国标字段被隐式转换 | 初始化/创建账号显式检查字符串；级联编号/域/别名保留字符串；HTTP验证返回业务错误且不写入坏数据 |
| 已有删除账号API缺少页面入口 | 用户表增加确认删除入口；当前登录账号禁用，关联资源失败保持提示；HTTP验证删除后旧登录401 |
