# 平台录像按通道全天回放

日期：2026-11-07。完善现有录像回放页面，没有新增业务模块、后端接口、依赖或数据库迁移。

## 可用行为

- 平台录像默认按通道、日期进入00:00—24:00时间轴。自动选择已有录像的通道和最新归档日期，已保存的选择优先；用户选择无录像日期时不会擅自改成其他日期。
- 蓝色为已确认录像区间，灰色为未索引到录像。开始时间解析ZLMediaKit北京时间文件名，时长读取文件真实媒体metadata，不使用计划分段长度或下个文件开始时间伪造覆盖。
- 点击时间轴、键盘操作时间轴，或输入HH:mm:ss定位。相邻分段自动接续；重叠分段接续时不倒退播放。同日最后一段结束后停止，不自动播放第二天。
- 默认跳过无录像时段，也可关闭。在真实空档定位时明确提示，不能把断流空档当成录像播放。metadata未确认的文件不涂成蓝色，支持重读及原分段入口。
- 支持播放/暂停、0.5/1/2/4倍速、声音开关、全屏请求及当前分段下载。原“分段文件与下载”折叠保留。
- 按账号、通道及日期保存当前定位，刷新恢复选择及定位，不自动播放。切换通道、日期或离开页面会卸载播放源及取消未完成的metadata读取。
- 读取前一日文件的真实时长，处理跨午夜分段；当前日播放从文件内部对应偏移开始。并发读取最多3个文件，每个12秒截止，已确认时段可提前使用，追加归档沿用已确认的时长缓存。

## 数据与权限

复用既有`/recording-jobs?kind=scheduled&daily=1`和`?kind=download`，读取范围仍受既有最近200个通道日及导出任务限制。所有播放、metadata和下载经过原同源鉴权代理，文件始终使用真实所属jobId；浏览器不获取媒体管理凭据。

时间轴展示计划录制的归档文件。设备导出文件的生成时刻不是原录像时刻，因此不混入全天覆盖；仍可从分段列表/录像任务下载。设备录像来源保留既有国标查询及点播流程。本轮没有将底层分段文件合成一个全天文件，也没有增加整日合并下载；交界处可能短暂缓冲，属于自动切换播放。
