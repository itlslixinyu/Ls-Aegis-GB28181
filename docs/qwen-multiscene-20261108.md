## 原始输出说明的问题

正常白天图已生成：

```json
{"name":"汽车","color":"白色","position":"画面中下部，道路交叉口附近"}
```

夜间图已生成：

```json
{"name":"车辆","color":"白色","position":"中下部"}
```

这两例不是模型没有看到车辆，而是`normalizeQwenCaption`对结构化物体描述按逗号、分号拆句后，把不同物体共享的位置片段当成生成循环。例如“中下部）”或“左上角）”重复就可能触发`QWEN_INVALID_RESULT`。因此“模型原始输出有车”和“平台能返回可用描述”必须分开验收。

反光图则包含真正的完整重复条目，且具体归类无法从模糊画面可靠确认，不能简单取消全部重复校验来让它通过。人物图的无依据摄像头、屏幕图的时间戳也说明：格式正确不等于视觉事实和指令遵循都正确。
