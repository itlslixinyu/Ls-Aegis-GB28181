# 空闲本地录像索引（2026-11-08）

本轮在现有智能检索中增加后台预索引，不新增业务模块。默认配置为 1024 MiB、最近 7 天，可在“模型配置 → 本地接入 → 空闲本地索引”保存并启停。浏览器关闭不影响后台运行，平台后端必须保持启动。

## 存储与恢复

迁移 023 新增 ai_index_files、ai_index_frames 和 ai_index_storage。索引代表图、512维中文图文特征、原文件版本和时间偏移保存在本机 data/platform.db；不会另存视频切片。原录像仍保存在原媒体目录。容量是图片、特征及每帧128字节估计元数据的逻辑预算，不是整个SQLite文件或原录像容量；数据库空闲页可以复用，WAL和其它业务数据不计入此预算，不在业务运行时VACUUM。

每完成一帧在短事务中提交图像、特征和游标。30秒扫描窗口的待处理变化帧也保存，暂停、异常或平台重启后续建，不重新扫描已提交窗口。原文件指纹、模型/策略版本变化时重建对应文件；原文件删除时索引级联回收。缺失文件退避重试，不阻塞其它通道。

按录像时间保留最近N天；容量不足淘汰较旧索引，24小时内不立即重建被淘汰文件，配置调整可重新排队。清理每批最多32帧；只删除索引，不删除原录像、计划或历史任务。

## 采样与检索

后台按每30秒窗口低分辨率变化扫描，合并5秒内变化并补充设备事件和定期代表帧。仅读取已完成录像分段，跳过活动录像尾段与收尾状态。不持续点播摄像机。

文字和参考图查询仍使用原通道与时间范围：每个源文件验证权限和指纹后优先匹配持久特征，跨文件只物化前24个候选图，再对少量候选附近精查，保留原文件/时间定位。未完成或已过期、版本不匹配的索引仍走原按需补查流程。DeepSeek保持可选，最多复核前4张候选、一次请求；无密钥不影响本地检索。

这是采样相似检索，不能证明整段录像绝对不存在目标；短暂、小目标和模型相似度误判仍可能漏检。结果沿用候选与覆盖不完整标记，不把相似度冒充识别事实。千问摘要质量问题不属于本轮已解决项。

## 资源与权限

后台单任务、单线程低优先级解码/推理；人工预览租约、设备回放、平台录像传输、前台分析/检索到来时让出资源。传输结束后短暂等待再恢复。录像内部租约不误算人工预览；录像启动/收尾、录制路数达到4路、可用内存不足2GiB、系统CPU高于45%、磁盘可用空间不足2GiB时等待。每250毫秒检查正在执行的后台步骤，取消FFmpeg/模型工作，游标不超前提交。资源探测是保护策略，不是硬实时性能保证。

启用时绑定当前管理员，逐步检查其AI/录像/设备权限。权限撤销或本地接入关闭后停止；配置及状态接口要求 ai.configure。搜索从授权录像清单出发，索引没有全局图片下载入口，不跨用户暴露录像。密钥不写索引、不回传浏览器。
