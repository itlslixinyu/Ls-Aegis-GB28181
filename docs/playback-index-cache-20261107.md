# 回放索引复用与初始首帧

当前行为已按用户后续要求改为[当前时段无录像](playback-current-gap-20261107.md)，取消首次自动跳至有录像时间；本文首帧自动定位部分仅为历史记录，索引共享缓存仍保留。

## 已实现

- `frontend/src/archive-duration-cache.ts`：按账号和文件地址共享已确认的正数时长，去重并发探测；缓存有效期 30 分钟、上限 1024 条，通过 sessionStorage 在当前标签页刷新后恢复。失败不缓存，权限仍由服务端对文件请求校验。
- `frontend/src/components/ArchiveDayPlayer.vue`：多个窗口及关闭重拖复用时长；先探测当前定位附近和较早录像，增量发布可用时段，不等待全部文件探测完才显示首帧。取消单个窗口不影响其他订阅者，最后一个订阅者离开才取消探测。
- `frontend/src/components/PlaybackWall.vue`：首次加入平台录像时，统一时钟定位已确认的首段录像并显示暂停首帧。后台发现更早段可在初始暂停阶段校正；用户手动定位或开始播放后不覆盖其位置。所有窗口仍共用时间轴，不分别跳到不同时间。
- 初始准备过程不再错误显示“该通道此时无影像”；真实无文件、加载错误仍保留明确状态。新文件或缓存过期仍需要探测，首次访问不承诺零等待。

## 边界

设备录像的目录查询与国标兼容性未在本次改动中扩展。录像空档处不能伪装成同一时间的实际影像；初次自动选首段与用户主动定位空档分开处理。
