# 业务页面统一优化验收

日期：2026-11-01。范围为雷铄御警 / Ls-Aegis 现有业务界面，不新增菜单、业务模块、接口或数据库迁移。

## 参考与实现

参考用户已登录的 OA 平台 `https://oa.ls.hb.cn/system/dict`：紧凑的筛选工具栏、浅色表头、清晰边界、规整分页，以及新增弹窗中的标题、字段对齐和底部按钮。参考弹窗仅打开查看并取消，没有提交或修改 OA 数据；没有复制其业务记录或保存凭据。

保留雷铄御警的盾形标志、蓝色品牌、浅色管理界面和暗色视频区域，采用 Arco Design 方向的企业后台视觉。字段和业务行为以本项目现有实现为准。

主要文件：

- `frontend/business.css`：统一业务页和弹窗的共享样式。
- `frontend/src/components/DialogHeading.vue`：统一19个弹窗的标题及关闭入口，沿用原生 dialog 和忙碌状态。
- 11个现有业务组件：应用共享页面、筛选、表格和弹窗结构；14个表格增加列标题语义及可键盘聚焦的滚动区。
- `frontend/src/main.ts`：加载业务样式。

## 界面规则

- 标题、描述及主要操作置于独立标题卡片；列表、参数、详情使用统一面板间距。
- 筛选项使用一致的标签、白底输入框和间距；日期时间控件按可用宽度自动分行，避免隐藏时间。
- 表格统一表头、行高、边框、悬停、状态标识和分页；时间与国标编号保持完整显示。长表格在局部滚动，桌面固定操作列，窄屏取消横向固定，避免遮挡数据。审计的“资源”列保持普通数据列。
- 空表头与空态合并为连续区域，避免重复空白；原有加载、错误、离线、未配置与权限提示保留。
- 弹窗统一居中标题、关闭图标、标签对齐、必填标识和底部操作区。多列长表单在窄屏切换为单列，弹窗内部滚动，标题与底部按钮保持可见。首个适用字段获得自动焦点，保留 Escape 关闭。
- 用户角色显示中文状态标识，配置及审计页补充说明和面板标题。

## 实际验证

`npm run typecheck`、`npm run build`通过；现有 `npm test` 69项全部通过。

桌面使用隔离 UI 服务逐页检查现有14个菜单：

| 分组 | 页面 |
| --- | --- |
| 基础管理 | 接入配置、用户管理、分组授权、国标设备 |
| 视频业务 | 实时监控、录像计划、录像回放、录像任务 |
| 事件与位置 | 订阅管理、告警管理、设备地图、历史轨迹 |
| 平台运维 | 国标级联、操作审计 |

逐类检查19个原生业务弹窗，包括新增/编辑、设备密码与传输、通道、分组移入与授权、告警详情、位置、录像计划、级联共享和删除确认。删除确认仅打开并取消；没有提交删除、密码或授权变更。

在 `127.0.0.1:3001` 的临时数据库中实际新建测试分组、修改停用录像计划的保留天数，保存和列表回填正常；查询示例轨迹正常。该环境使用显式标注“[测试]”的数据，未启用 SIP 或媒体，不构成真实设备测试。

只读账户检查：只显示授权设备，不显示其他分组的设备；没有设备写入入口，告警弹窗没有确认或处置按钮。浏览器检查未发现控制台 error。

1440×960 桌面及390×844窄屏实测。窄屏重点检查设备筛选与表格、录像计划、级联长表单、告警日期筛选、历史轨迹查询；轨迹页 DOM 测量的页面宽度与视口内容宽度均为375px，无整页横向溢出。临时视口已恢复，隔离服务和标签已关闭。

正式 `localhost:3000` 使用原有 admin 会话核对：仍为1个用户、1条原设备；SQLite完整性为ok，外键错误0。首页、主JS、主CSS及健康接口均200。正式业务数据和账户凭据没有修改；保留正式页面与 OA 参考标签。
