# 分组授权全流程与表格留白修复（2026-11-05）

本轮使用临时内存平台、23个明确标识的模拟设备档案和隔离测试账号；不改正式账号授权，不连接或控制真实设备，不把模拟档案作为真实NVR接入验收。

## 修复

- 通用业务表格容器原有 `min-height:160px`，一行表格只有约100px（44px表头+56px数据行）时仍留下约60px空白。将业务表格容器最小高度改为0，随实际表格收缩，保留长表格的最大高度及内部滚动。不是强行压低长文本数据行；空态提示区域保留原有布局。
- 分组授权弹窗以前不能识别其他页面刚保存的新范围。GET `/users/{id}/groups` 增加 `version`；界面PUT时提交该版本，后端在事务内核对，不一致返回409 `AUTHORIZATION_CONFLICT`，保留已有授权。旧调用不传版本仍兼容。
- 授权冲突时保留用户选择，阻止继续提交旧版本，提供“重新读取”；未选用户、读取中、读取失败及保存中均禁止提交。授权选项在未就绪时禁用。
- 删除操作补充重复提交保护；分组列表迟到的失败响应不覆盖新请求结果。默认分组仍可编辑名称/说明，不可删除。

## 实际浏览器验证

脚本：`node scripts/groups-browser-test.mjs`。

1. 新建：名称必填、纯空白拒绝、重复名称拒绝；成功创建两个分组。
2. 编辑：修改名称和说明，列表更新。
3. 移入：23个模拟设备跨20条分页选择并移动两台；按设备名称精确搜索后移动第三台；接口核对实际归属及数量。
4. 用户授权：未就绪时不能提交；模拟另一页面并发保存，旧弹窗409后重新读取；授权指定分组后测试用户可见2台设备，清空授权后立即可见0台。
5. 删除：包含设备时按钮禁用；空组仍有账号授权时后端拒绝；移回设备并清空授权后成功删除两个组，仅保留默认组。
6. 表格尺寸：删除后单行分组，在1280、3380、390宽度下容器多余高度均0，普通行56px；筛选到单行的用户表格多余高度0；订阅空表0、级联空表1px，没有页面横向溢出。空态提示单元格仍可保留170px展示说明。
