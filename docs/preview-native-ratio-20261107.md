# 实时预览原始比例修正

> 此处记录第一版方案。用户反馈整面左右留白后，已替换为铺满监控区的固定网格，当前行为见 [监控墙铺满布局](preview-wall-fill-20261107.md)。下文的缩窄墙宽与原比例窗口计算已撤销。

视频区域跟随播放器报告的真实宽高，未取得元数据时默认 16:9；原比例显示仍为默认值。标题栏、状态栏与边框单独计入窗口高度，监控墙按可用宽高调整尺寸，不再用等分高度压扁视频区域。分辨率变化时重新计算，适用于不同厂商 IPC/NVR 的通道，不按品牌硬编码。混合比例行以最高窗口决定行高；空间不足时允许监控区域内部滚动，保留最小窗口宽度。

修改：`Monitoring.vue` 管理原始比例与监控墙尺寸、卸载时释放 ResizeObserver；`LivePlayer.vue` 在元数据及视频尺寸变化时通知父组件；`video-business.css` 按原比例生成视频区域并分离标题、状态栏空间。主子码流、音量、截图、放大和全屏入口保留；用户主动选择拉伸或裁剪的行为保留。

验证：类型检查、构建及 53 项前端组件/API 测试通过。浏览器实测海康测试摄像机主码流原始 1920×1080：1、4、9、16、25、36 分屏与双击放大还原的视频区域比例均约为 1.7778，390px 窄屏页面无横向溢出。4:3 元数据与混合比例尺寸计算由组件测试覆盖，本次未接入真实 4:3 设备，也未重新验证设备固件或国标协议兼容性。未重启后端、媒体节点，未修改设备编码、正式录像计划或授权。
