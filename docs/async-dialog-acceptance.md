# 现有功能异步弹窗完善记录

日期：2026-11-01。范围仅为设备通道查看、分组移入设备；没有新增业务模块，没有修改正式设备档案、分组授权或接入配置。

## 已修复

1. 旧设备的通道读取晚于新设备返回时，会覆盖当前通道或错误提示。现在只接收当前请求，关闭弹窗及离开页面后忽略迟到响应。弹窗显示设备名称和国标编号。
2. 分组移入设备的搜索失败后仍保留旧列表，读取过程中也可以提交旧选择。现在读取期间禁用选择和确认，失败清空旧结果并显示重试提示；读取成功后恢复。失败不再显示“0台”，而是“数量未获取”。跨页选择保留，重新查询成功前禁止提交。
3. 分组弹窗立即打开并显示加载状态，关闭时取消本次界面请求的有效性。迟到响应不能再次打开弹窗或填入下次操作；关闭并不宣称已中断网络传输。

## 验证

- 新增 `backend/frontend-components.test.mjs`：直接执行现有 Vue 组件的 script setup，使用实际 Vue 响应式和可控响应顺序；不依赖 DOM，也不代替浏览器验收。最初4条测试均复现失败，修复后新增关闭/重新打开场景，共6条通过。
- `node --test --test-timeout=30000 backend/*.test.mjs`：86/86通过，包含既有角色、CSRF、资源归属、撤权及协议模拟回归。
- `npm run typecheck`、`npm run build`：通过；最终分页文案调整后重新构建通过。
- 隔离测试平台 `127.0.0.1:3001` 使用临时数据库和虚构设备，实际登录 qa-admin，正式账号和配置未改动。
- 浏览器：延迟旧设备/旧搜索的真实GET响应10秒，关闭后重新打开，当前设备与当前列表均保持正确；列表503时旧行消失、确认禁用，重试成功恢复。
- 桌面1440×960和窄屏390×844检查：错误提示及关闭/查询操作可见；窄屏页面宽390、弹窗宽366，弹窗无横向内容溢出。临时视口覆盖在验收后重置。
- 正式3000端口首页和健康接口均为200，SQLite正常；SIP仍未启用、媒体仍未配置。隔离测试页及临时服务已关闭，故障文件和测试日志已清理。

测试脚本增加仅限隔离环境的 `passThrough` GET延迟，仍走原鉴权接口；未修改正式API。浏览器只读取和选择测试设备，未提交分组调整。真实设备、媒体和上级平台尚未部署，视频播放、真实云台动作、真实录像和公网链路仍待实机验收。
