# 视频业务页面优化（2026-11-05）

本次覆盖实时监控、录像计划、录像回放和录像任务，保持雷铄御警政企蓝风格及现有业务范围。

## 页面调整

- 实时监控：统一通道侧栏、检索、分屏工具栏与画面区的层次，增加当前窗口提示；保留1、4、9、16、25、36分屏、双击放大与Esc还原，以及码流、声音和云台操作。
- 录像回放：平台录像与设备录像使用统一来源切换栏；筛选控件限制宽度，导出说明放在查询条件下方，调整空状态及播放器外观。
- 录像计划：统一概览、计划表格与创建弹窗间距，突出计划名称；保留原有校验、保存和启停流程。
- 录像任务：统一任务状态、文件展开和回放弹窗，正常中断说明使用中性色，失败状态仍使用红色。归档文件概览汇总当前加载任务的文件数量。
- 普通屏、宽屏与窄屏采用响应式排列，表格保留内部滚动，避免页面整体横向溢出。

主要文件：`frontend/video-business.css`、`frontend/src/main.ts`、`frontend/src/components/Monitoring.vue`、`Records.vue`、`RecordingCenter.vue`。

## 修复

录像文件回放地址原先重复追加`?play=1`，导致后端未能识别回放用途，仅有回放权限的账号可能被按下载权限拒绝。现在地址只追加一次；服务端仍分别检查回放与下载权限。
