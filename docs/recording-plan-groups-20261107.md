# 分组录像计划

## 行为与实现

- 新建时选择现有设备分组，搜索名称、编号、设备名，勾选组内通道；支持全选当前搜索结果、清空选择，切组清空旧选择。通道资源按100路分页读取，已在隔离128路录像机验证可选第65/66路，不会只显示前32路。
- 主列表按分组计划展示，统一配置星期、全天/自定义时间、保留天数和分段。每条计划可统一启停、编辑、删除；“通道明细”弹窗查看每路最近执行日期的状态、过程和文件，完整历史仍在录像任务查看。
- 每路保留独立子计划，复用原调度、中断告警、按日汇总、文件及恢复路径。一路失败不连带停止其它路。执行中不能编辑/删除，先停用并等收尾；停用后状态变更由既有调度循环完成。
- 分组及通道是创建/编辑时显式选择的快照，新加入分组的设备不会自动录制。通道移出分组后，已有计划仍保留原选择；下次编辑须重新确认有效的组内通道。服务端拒绝跨组、已移除、重复或空通道列表。
- 旧单通道计划以单通道条目兼容展示，不按相同名称强制合并、不修改在录配置。首次编辑升级成分组计划；仍选中的通道保留原子计划ID与执行关联。移除子计划不会删除其归档文件。

## 接口与存储

`GET/POST /api/v1/recording-plan-groups`、`PUT/DELETE /api/v1/recording-plan-groups/{id}`、`PUT .../{id}/enabled`、`GET .../{id}/channels`。

- 受原 `plans.manage` 管理员权限及CSRF保护；原单通道接口保留兼容，但已纳入分组的子计划禁止通过旧接口单独改动。
- 创建使用 `Idempotency-Key`，相同账号相同键和内容复用结果，改用相同键提交不同内容返回409。更新/启停/删除传 `version`，冲突返回409。组内批量写入使用同步SQLite事务，校验失败或任一路时间重叠时全部回滚。
- 迁移13脚本：`scripts/migrations/013-recording-plan-groups.sql`，新增 `recording_plan_groups`、`recording_plan_members` 和任务计划查询索引。启动自动执行；原 `recording_plans`、任务和文件记录不重建。
- 前端主要改动：`frontend/src/components/RecordingCenter.vue`；服务层：`backend/services/recording-plan-groups.mjs`，路由、权限映射和通道返回分组ID同步更新。
