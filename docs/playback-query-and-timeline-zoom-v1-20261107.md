# 回放查询区与时间轴缩放第一版（2026-11-07）

## 当前交互

平台录像和设备录像都采用左侧“上方通道资源、下方查询区”的布局。通道多时仅资源列表上下滚动，开始时间、结束时间及查询按钮保持在下方。日期与时间统一按界面标注的北京时间解释，条件按账号保留。

点击资源先选择通道，不立即发起设备录像检索或建立播放器。点击“查询录像”或拖入画面时，校验开始与结束时间有效、开始早于结束且跨度不超过24小时；拖拽使用当前填写的同一范围。缓存以通道及已应用查询范围关联，条件变更后不能把旧结果当成本次查询。查询成功后才应用新范围；新范围替换旧区间窗口，避免多窗口混用不同时间段。同一区间继续支持多个通道和同通道重复窗口。

**查询范围与显示缩放相互独立。** 查询5分钟只限制本次可回放和覆盖的录像，不强制把时间轴显示成5分钟。默认可看全天，再按需要放大到小时或分钟；缩放、平移不改变查询条件和当前播放位置，不重新检索。

- 鼠标指向时间轴，滚轮向上放大、向下缩小。逐级为全天、6小时、1小时、10分钟、5分钟、1分钟。围绕鼠标指向时刻缩放，全天按自然日对齐。
- 提供“全天 / 小时 / 分钟”快捷切换和加减按钮，左右箭头用于平移视图。
- 放大到一分钟后显示秒级刻度，单击按秒定位；时间输入框仍可直接精确定位。
- 按住鼠标左键左右拖动平移时间轴；移动超过3px按平移处理，松开不跳转播放位置。普通单击才定位。指针取消时不会错误定位。
- 所有窗口共用底部这一条时间轴，不增加通道专属轨道。
- 时间轴允许查看查询区间之外的刻度，但录像覆盖和实际定位受已应用查询起止限制。

## 实现

`record-range.ts` 统一校验和北京时间到UTC转换，拒绝空值、非法日历日期、倒置或超过24小时的范围。跨午夜仍以起始自然日为锚点计算连续秒数，时间轴可以平移到次日，刻度明确标记次日。

`RecordingCenter.vue` 管理平台录像草稿查询条件、已应用范围及按范围区分的通道缓存；`Records.vue` 对设备RecordInfo请求使用同一校验和转换。`PlaybackWall.vue` 将查询边界与显示窗口分开，独立管理缩放、平移、指针捕获和点击定位。`ArchiveDayPlayer.vue` 支持跨日窗口结束界限，复用原有真实文件索引、同步时钟与取消机制。接口、数据库和设备编码不变，无迁移。

## 验证

- 类型检查和生产构建通过；前端组件/API、录像服务及隔离HTTP生命周期共98项相关测试通过。
- 浏览器查询12:00—12:05后，默认时间轴仍显示00:00—24:00；滚轮逐级放大到一分钟，刻度出现秒，查询输入保持不变。
- 实际鼠标事件点击定位12:00:17；滚轮缩小时该播放位置不变。
- 实际按住左键拖动后，显示范围从11:59:47—12:00:47移到11:59:59—12:00:59，播放位置仍是12:00:17；随后单击精确定位12:00:21，实际video.currentTime=21、readyState=4、1920×1080。
- 页面只有一个range进度条；没有通道分轨。
- 设备录像128路列表：列表内容高7692px，容器高737px并可独立滚动，查询表单位于列表下方。起止倒置时浏览器显示业务错误，不提交检索。
- 1280×720下文档宽1280、高720，工作区底部688px，无整页溢出；宽屏第一版效果见截图。
- 隔离测试停止后，正式录像计划哈希与测试前一致；录像哨兵仍recording，recordStopped=0。未重启正式平台或媒体节点。

浏览器回放使用隔离通道和本机已有录像样本，未伪装成真实多通道录像机。设备查询请求及范围缓存已做契约回归，尚无真实多通道录像机验证厂商端查询行为。
