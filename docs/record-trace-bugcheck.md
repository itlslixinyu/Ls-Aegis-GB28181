# 录像与轨迹缺陷检查

日期：2026-11-02。仅修复现有功能，正式数据、账号和接入配置未更改。

## 修复内容

| 问题 | 修复后行为 |
| --- | --- |
| 录像条件变更后旧请求仍占用查询，旧录像与新条件可能不一致 | 条件变化立即清空旧结果和回放，释放界面忙碌状态；迟到任务响应不能覆盖新查询 |
| 离开录像页面后，导出返回成功仍触发跳转 | 后台已提交的导出任务继续，已离开的页面不再发出导航事件 |
| 轨迹条件变化后不能马上重查 | 清除旧查询状态后允许立即重查；旧请求结束不能解除新请求的忙碌状态 |
| 加载后续轨迹遇到暂时故障会清空已有采样 | 网络故障、5xx或429保留点位与游标，可原页重试；权限、资源不存在或失效参数错误仍清除点位 |

录像增加前置时间范围校验：开始必须早于结束，最大24小时，非法输入不提交任务。前端请求错误增加HTTP状态与业务错误码，中文提示、会话及CSRF处理保持原有契约；非JSON权限拒绝也可识别。
