# 实时监控批量开关

“监控画面”标题栏增加“打开全部通道”和“关闭全部通道”，保持现有政企蓝样式，窄屏自动换行。

打开全部按当前搜索条件分页检索服务端已授权通道，不局限于左侧当前的 32 条；只添加设备和通道都在线的结果，保留现有窗口且不重复添加同一通道。按需扩展到 1/4/9/16/25/36 档，保持已有较大的分屏布局，最多 36 路，超限明确提示。提示区分“已安排预览”与各窗口真实播放结果。无在线通道或请求失败明确提示，失败保留原有预览。

关闭全部清空本页所有槽位、取消批量打开并还原放大状态，通过现有播放器卸载逻辑释放观看者。不停止录像计划、其他页面或其他用户的观看。关闭、搜索变化、刷新列表、手动选择通道、改变布局及离开页面都会使迟到的批量结果失效。

修改文件：`frontend/src/components/Monitoring.vue`、`frontend/video-business.css`、`backend/frontend-components.test.mjs`。复用原有授权与分页 API，无后端接口或数据库变化，无需重启后端。

验证：类型检查与构建通过；组件测试覆盖跨页在线筛选、去重、保留原位置、扩展分屏、36 路上限、网络错误、关闭及手动操作后的迟到响应、无在线通道。浏览器以当前现有海康通道实测批量打开，视频 1920×1080 实际播放并推进，重复打开仍为一路，关闭全部后 video 元素为 0。390px 窄屏两个按钮未越出页面。未进行 36 路真机并发测试，也没有重新验证国标协议兼容性。实际效果截图 `.tmp/monitor-bulk-open.png`。
