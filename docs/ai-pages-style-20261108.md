# 智能检索页面布局验收（2026-11-08）

本轮仅调整既有画面分析、录像检索、模型配置页面，不增加业务模块，不修改模型配置或录像计划，不重启后端。

## 页面结构

- 画面分析：参照录像回放的工作区，左侧为来源和分析要求，右侧为真实图片、状态、中文摘要与标签；分析记录独立为表格页签，保留筛选、分页和详情弹窗。
- 录像检索：左侧为范围、参考图/通道与底部查询条件，右侧为结果卡片；历史分析查询改为表格入口，查看既有结果不会新建分析任务。部分完成状态使用中文。
- 模型配置：保留本地接入和大模型接入两页签；本地开关、告警设置、模型清单分区，大模型参数和连接状态分栏。
- 修正固定高度下卡片压缩截断、结果摘要被全局样式缩窄、无效背景变量和桌面内容超高。待完成预览在离开当前列表后仍刷新，失去详情权限时清理对应图片。
