## 雷铄御警的对应实现

保持现有14个业务页面及使用顺序，没有增加OA、库存或财务模块。

| 一级分组 | 二级入口 |
| --- | --- |
| 基础管理 | 接入配置、用户管理、分组授权、国标设备 |
| 视频业务 | 实时监控、录像计划、录像回放、录像任务 |
| 事件与位置 | 订阅管理、告警管理、设备地图、历史轨迹 |
| 平台运维 | 国标级联、操作审计 |

1. 一级分组改为带图标和箭头的可折叠菜单，互斥展开；子菜单缩进显示。桌面收起后仅显示分组图标，点击图标可展开对应分组。
2. 面包屑显示“雷铄御警 / 所属分组 / 当前页面”；页签切换和页面内跳转都会定位对应分组。
3. 增加菜单快速定位：点击搜索或Ctrl/Cmd+K打开，仅搜索当前账号可见的功能及分组。支持无结果提示、点击跳转和Escape关闭；已有业务弹窗打开时不抢占快捷键。
4. 已打开页面以页签显示，可切换、关闭；关闭当前页签回到邻近页面，保留至少一个页面。只记录访问入口，不缓存组件状态，也不让后台页继续持有视频；切页仍走既有组件卸载和资源回收。
5. 页签不写入浏览器存储，刷新后回到设备页；账号切换清理旧页签与选中位置。只读用户仍只有原有8项入口，搜索和页签不提供管理员功能。
6. 手机沿用抽屉导航，分组互斥展开、选中后关闭，Escape及焦点返回有效；从桌面收起模式进入手机菜单时恢复完整文字导航。

## 2026-11-05 一级顺序及刷新保持

按用户确认，一级分组调整为“视频业务 → 事件与位置 → 平台运维 → 基础管理”，各组子菜单顺序不变。

`frontend/src/App.vue`增加按账号保存的已打开页签，并用地址片段`#page=jobs`等记录当前页面。初始化会等待登录身份及权限就绪，优先恢复有权访问的地址页，再使用当前标签页的账号级会话记录；页签去重并过滤失权菜单。切换账号会清理原账号的页签记录。未改变后端权限或录像调度。

修改前的正式浏览器14页常规刷新均能保持当前页，未复现整体跳回；实际发现已打开页签未恢复。本轮补齐页签恢复及地址恢复路径，防止存储缺失时丢失当前页。

验证：类型检查、构建、48项前端相关回归通过。正式浏览器逐一打开14个菜单并刷新，当前页及页签列表一致；关闭页签后刷新不重新出现。录像回放的平台来源、通道、2026-11-05日期、第2页，以及设备来源、通道和起止时间均刷新保持。清空测试浏览器会话存储后，地址仍可恢复录像任务页。隔离只回放权限账号面对`#page=config`及包含配置/用户管理的旧页签时，刷新仍回到有权访问的录像回放页，不出现管理页签。

正式浏览器仅只读操作；未改正式账号、配置、设备或录像计划。一次隔离浏览器运行在账号菜单点击超时，重跑完整流程通过；没有将该自动化时序问题描述为权限验证通过。最新前端已构建，无需重启服务。
