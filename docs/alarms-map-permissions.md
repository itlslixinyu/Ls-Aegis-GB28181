# 告警、地图与设备分组权限

v0.7.0，2026-11-01。以下功能已完成本机协议/HTTP测试和隔离数据库界面验证；真实设备主动通知、真实地图服务及现场设备尚未验收。

## 设备分组与授权

管理员在“分组权限”建立平面分组，填写名称与说明，在设备分配窗口选择设备移入目标组；单次最多200台。可跨设备分页勾选，移动在一个事务内完成，任一设备不存在则整批不变。设备必须有一个分组；默认“未分组”不能编辑或删除，含设备或授权的分组不能删除。

在“只读账号授权”选择账号并勾选可见分组，保存后替换完整授权列表。管理员拥有全部设备访问权；viewer可授权多个分组，新建viewer默认无设备访问权。账号创建入口仍在“账号管理”。

权限在服务端统一检查，覆盖设备、通道、数量统计、目录任务、录像查询与回放、自己的导出任务/文件、告警、地图和实时播放。导出资源还要求账号所有权；不能仅因同组就读取他人的导出。历史数据跟随设备当前分组，移组后原组用户失去该设备历史资源访问权。设备删除后的历史告警仅管理员可见。

移组、撤权和删除用户后主动终止失权观看连接及MP4传输，另有每秒复核；不终止同一源流的其他合法观看者。退出账号同时中止该登录会话的文件传输。

升级迁移8保留已有账号/设备：旧设备归入默认组，已有viewer获得默认组授权，保持升级前访问；迁移后新建viewer须显式授权。若需要收紧旧用户，升级后逐个调整授权。

## 告警接入与处置

开启SIP并让真实设备完成Digest注册。设备主动发来的MANSCDP Alarm Notify须来自已注册端点，DeviceID须是设备本身或本设备已有目录通道；不接受其他设备的通道。也可在“订阅管理”启用Alarm订阅；详情见[订阅与历史轨迹](subscriptions-and-trajectories.md)。

校验SN、告警级别1～4、方法、时间、文字长度和可选坐标；无时区时间按UTC+08解释。有效告警落库后异步发送Alarm业务Response/Result OK。去重键包含设备、通知目标、事件时间、方法、类型和描述；重复消息累计次数，不重新打开已处置事件。每设备每分钟最多100条新事件，超过返回SIP 486。

“告警管理”支持关键词、分组、级别、状态和时间筛选、分页及详情，每10秒刷新。顶部数量为当前授权范围总计，不随列表筛选改变。流程为待确认→待处置→已处置；管理员操作，处置说明必填。操作保留账号、时间及说明，版本校验防止两次并发操作覆盖；冲突后刷新详情再处理。viewer只能查看。

## 地图与设备定位

地图使用WGS84经纬度。管理员可打开位置编辑、填写经纬度和说明，或点击“地图取点”后在地图选择位置保存。列表包括未定位设备；在线、离线、未处置告警分别标识，可按分组和名称过滤，选中设备后读取授权通道并进入预览。

已注册设备的MobilePosition Notify可更新设备位置；旧时间及超过当前时间5分钟的未来时间受到保护。手工位置优先于设备通知，清除手工位置后，后续有效通知可以恢复定位。设备MobilePosition另存历史采样，可在“历史轨迹”检索；手工点位不会生成轨迹。

默认未配置地理底图，页面显示明确标记的经纬度网格，不包含道路和行政区划，也不会请求外部地图。

如需底图，在`.env`填写允许使用的自建XYZ栅格瓦片模板及署名，再重启：

```dotenv
MAP_TILE_URL=https://tiles.example.org/{z}/{x}/{y}.png
MAP_ATTRIBUTION=本单位地图数据服务
```

示例域名需换成实际服务。底图使用与WGS84兼容的Web Mercator XYZ瓦片；尚未实现GCJ-02/BD-09转换，坐标系不匹配会产生偏移。署名显示为纯文本，按所用服务要求填写。

浏览器请求同源鉴权代理，上游地址/查询密钥仅留后端。仅允许HTTP(S)，拒绝URL内用户名/密码、重定向和非PNG/JPEG/WebP响应；缩放0～19，7秒超时，单瓦片最大2MiB，浏览器私有缓存7天。未配置服务返回503；异常服务返回502。地图最多返回5000台授权设备，未进行大规模容量验收。
