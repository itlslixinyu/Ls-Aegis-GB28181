# 告警摘要与相近画面复用

本轮代码与隔离测试已完成；用户手动结束旧进程后，新后端已加载本轮修改。真实摘要质量仍未通过验收，详见下方补充。

- `backend/ai/qwen-runner.mjs`：优化配置的提示优先描述可见人车、数量（清楚可数时）、颜色、位置和姿态，背景后置；摘要上限由40字改为100字，输出预算224 tokens。仍不推测身份、意图或单帧运动过程，不强行补造人车。提示版本提升为p4g1，旧提示的精确图像缓存不会冒充新版结果。CPU线程数、图像分辨率及运行资源保护不变。
- `backend/ai/alarm-similarity.mjs`：320×180低成本彩色像素比较，同时约束平均差异、显著变化像素比例和局部网格差异。压缩轻微变化可通过，小块新增目标及明显亮度变化的测试样本被拒绝。不是目标识别算法，不能保证发现所有微小或低对比度目标；不按全局相似分强行合并。
- `backend/ai/alarm-analysis.mjs`：同账号、同通道、同提示模型版本、两分钟内未过期的成功分析可作复用基准；只参考真实推理结果，不以复用结果继续形成无限链。保留每条告警、当前图片和拍摄时间，只复用摘要及标签，usage标记cached及similarScene。比较失败回退模型，权限撤销及资源让位继续生效。未改设备告警上报、抓图间隔、录像计划或媒体会话。
- `backend/alarm-analysis.test.mjs`：增加相近复用、过期重新分析、跨账号隔离、压缩与局部变化覆盖。告警服务/HTTP及AI服务合计25项测试通过。

真实告警抓图的新提示推理尚未完成：验证脚本检测到可用内存不足4GiB，主动跳过，避免与预览、录像争抢资源。不能据隔离测试宣称真实人车识别精度改善。旧告警摘要不会批量重算或覆盖；本轮正式启用后需以实际告警抓图验收关键词质量。

正式启用后使用同一本机模型对真实海康录像帧分析，两次输出仍有车辆肯定/否定矛盾，一次缺少标签，另一次将否定句作标签。因此摘要质量不得标记通过。自定义输入、不同要求缓存隔离及原录像定位实际通过；计划与备份一致，预览和自动续录正常。见[正式验收](ai-local-custom-prompt-20261108.md)。
