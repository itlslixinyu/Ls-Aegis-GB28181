# AI文字与图片检索浏览器验收

2026-11-08，本轮不重启后端、不修改录像计划、账号授权或设备参数。浏览器使用已登录的Codex内置浏览器；期间控制接口超时，用户重新打开后恢复了核心验收。额外的临时空白验收页随后仍出现数据请求超时，已关闭，未据此声称所有多标签页问题均已解决。

## 发现与修复

1. AiSearch.vue上传新参考图片时，仅历史录像范围传localReference:true，“已有分析画面”范围仍传false，导致未接入DeepSeek时提示AI尚未启用。已统一使用本地参考图准备，不调用云端描述，不以参考图保存代替目标检测。
2. 开始新查询失败时，旧卡片仍留在页面。新查询现在清理旧结果、旧方法和旧任务显示，避免把上次结果误认为本次命中。
3. 分数依据结果visualScore是否存在分别显示“匹配度 / 相似度”，不随尚未提交的表单模式变化，也不称作识别置信度。
4. 有真实recording来源的卡片增加“可定位录像”提示，便于区分可回放结果与普通上传图片。

修改文件：frontend/src/components/AiSearch.vue；backend/frontend-components.test.mjs新增两个交互回归；backend/ai-http.test.mjs增加无云端密钥下本地参考图准备、检索及无权限账号访问断言。后端业务代码未变。
