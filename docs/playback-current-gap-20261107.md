# 当前时段无录像

**最新规则已按用户澄清改为[按窗口顺序选择基准](playback-window-reference-20261107.md)**：第一个有录像的有效窗口负责初始定位，其它窗口在该时刻无录像显示本文文案；不再采用本文“完全取消初始定位”的行为。

用户最新要求：拖入回放窗口后，当前时刻没有录像时显示“当前时段无录像”，不再自动跳至其它有录像时段。本规则替代先前的首次自动选首帧方案。

- `PlaybackWall.vue` 移除首次范围发布、补索引和播放按钮触发的自动跳到首段逻辑；拖入通道保持共享定位时间，所有窗口仍共用时间轴。
- `ArchiveDayPlayer.vue` 在确认无当前分段时显示“当前时段无录像”；索引未确认前保留准备状态，读取/解码错误继续独立提示。
- `LivePlayer.vue` 的设备录像空档使用相同文案。移除平台/设备页面自动计算首段定位的冗余绑定。
- 浏览器实际测试：零点拖入模拟013，索引完成后仍为00:00:00，窗口显示指定文案；点击播放不跳至22点录像。手动定位22:08:10显示640×360、readyState4；再定位10:00:00恢复提示且时间保持不变。
- 类型检查、生产构建和相关回归通过；未重启后端、未修改录像计划。设备录像的空档文案未做真机取流兼容性验收。
