# 国标设备管理页重排（2026-11-05）

保持雷铄御警政企蓝与既有业务范围，仅调整前端呈现和操作入口，不修改设备配置、国标编码、账号授权或后台接口。

## 页面调整

- 四个独立大卡片改为一条分隔清晰的资源概览，统一蓝色图标，在线设备保留绿色辅助状态；窄屏排为2×2。
- 检索、状态、分组筛选靠左排列，检索框在普通屏与3380宽屏均为320px，不再随视口无限拉长；增加重置筛选。
- 表格将设备名称和国标编号组合为“设备信息”，统一图标、编号次级文字、分组标记和通道数量。其他列维持居中。
- 直接显示“通道”和“同步目录”，编辑、传输设置、接入密码及删除收进“更多”浮层。原操作处理函数及服务端权限不变；只读账号没有管理菜单。
- 浮层位于浏览器顶层，避免表格滚动裁切；根据空间向上/向下展开，支持上下方向键、Home/End和Esc，缩放及用户滚动时关闭。焦点进入不触发自动滚动。

## 文件

`frontend/src/components/Devices.vue`、独立页样式 `frontend/devices.css` 与入口 `frontend/src/main.ts`。共用业务样式仍在 `frontend/business.css`，设备页新增规则已移入独立文件。
