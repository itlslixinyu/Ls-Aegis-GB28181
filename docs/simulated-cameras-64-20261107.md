# 正式平台中的64台模拟摄像机

**当前版本已增加测试视频**，以下“无视频源”描述为首次信令模拟阶段。视频与回放验证见[模拟视频与样例回放](simulated-camera-video-20261107.md)。

用户明确要求在“国标设备”中模拟64个摄像头。已在本机正式库新增独立分组“模拟摄像机（无视频源）”，设备名称为“模拟摄像机 001”至“模拟摄像机 064”，编号使用专用999999前缀，不与真实设备混用。每台一个独立通道。

## 实现及验证

- `scripts/simulate-cameras.mjs`：仅允许向本机网卡上的SIP服务发送信令。新增档案初始为未注册，不直接写在线状态；由64台软件模拟设备通过UDP Digest认证REGISTER、定时Keepalive和注册续期保持在线。
- 目录由正式页面的“同步目录”操作触发，模拟器回应Catalog，平台按原流程入库。数据库实查64台online、64条注册绑定、64条online通道。
- 本机模拟器进程19460持续运行。没有视频源，INVITE返回488，不把注册在线冒充可播放视频；不支持真实云台动作或设备录像。
- `backend/camera-simulator.test.mjs`：临时数据库和隔离UDP/TCP平台实测64台注册、64路心跳、64个目录同步和停止后注销，测试通过。模拟协议行为覆盖当前平台的GB28181实现，不代表厂商固件兼容性验收。
- 正式浏览器已核对模拟分组共64条、每页32条、两页，所有模拟设备均显示在线且有1路通道。保留真实海康摄像机，平台总数因此为65台、65路。
- 启动前在线备份存于 `backups/simulated-cameras-*/platform.db`，具体路径见 `.tmp/cameras64-out.log`。未修改正式用户授权，未新增或改变录像计划。

## 生命周期

模拟器运行期间持续在线，不随浏览器关闭停止；电脑重启后不会自动启动。状态查看 `.tmp/simulated-cameras/status.json`。将 `.tmp/simulated-cameras/control.json` 写为 `{"stop":true}` 可停止模拟器并注销这64台，档案保留，真实设备不受影响。

重新启动使用 `node --env-file-if-exists=.env scripts/simulate-cameras.mjs`，只会更新其专用模拟档案的临时认证信息；编号或分组被其它设备占用、仍有点播时会拒绝，不覆盖冲突设备。

本次先前启动的独立隔离64路测试服务已停止；用户查看的是正式平台国标设备页。截图 `.tmp/simulated-cameras64-20261107.png`。
