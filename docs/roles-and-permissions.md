# 角色、功能权限与设备范围

## 实现范围

沿用“用户管理”和“分组授权”入口，不增加业务菜单。用户管理包含“用户列表 / 角色配置”，可创建、编辑、删除自定义角色；用户列表“授权”设置角色及设备范围。姓名等个人资料仍独立维护。

| 层次 | 行为 |
| --- | --- |
| 功能权限 | 查看设备、实时预览、云台、录像查询/回放、录像导出/下载、告警查看/处置、地图查看/点位维护、轨迹、订阅查看/维护 |
| 数据范围 | 指定设备分组，或全部设备（含之后新增）；无分组时无设备访问权限 |
| 平台管理 | 接入配置、重启、设备接入维护、录像计划、用户/角色/分组授权、国标级联、审计保留给系统管理员 |

操作权限自动包含必要的查看权限，例如云台包含预览和设备查看，告警处置包含告警查看。无功能权限角色仍可登录和维护本人资料，但无业务菜单。角色名不是权限依据，展示用部门和职务不参与授权。

内置系统管理员、只读用户不可修改或删除。只读角色兼容既有查看、预览、回放、下载及位置/订阅查看功能；设备范围沿用原分组。自定义角色权限保存立即在服务端生效。指定分组范围不自动包含新分组，“全部设备”会包含新增设备。

## 权限校验与资源回收

服务端每次请求校验功能权限和设备范围，直接调用接口不能绕过界面。HTTP/WS观看、续租和文件传输持续校验，撤权回收目标观看者和对应传输，不影响其他账号。权限撤回停止失权用户的云台操作。已受理协议任务继续遵循原有超时和回收路径。

浏览器通过同源会话通知同步权限，15秒轮询和403刷新保留为降级路径。菜单、页面页签、云台/告警/点位/订阅按钮和录像导出/下载入口跟随权限；权限或范围变化重新挂载业务页面，避免继续显示旧范围数据。平台配置和个人外观配置是不同功能，后者仍对本人开放。

平台计划录像允许在角色的设备范围内查看和回放、按下载权限获取文件；普通角色不能结束计划录像。设备录像导出继续按账号归属隔离。下载权限控制平台导出及附件下载请求，观看本身不提供防录屏或DRM能力。

内置角色不可改删，在用自定义角色不可删除。账号授权及角色编辑具有版本冲突保护。禁止修改当前登录账号的授权，必须保留至少一个系统管理员；有录像或级联资源的管理员须先处理资源后才能降级。所有管理写操作要求CSRF并记录审计。

## 接口

| 方法与路径 | 用途 |
| --- | --- |
| `GET /api/v1/roles` | 角色列表、权限目录、关联账号数 |
| `POST /api/v1/roles` | 创建自定义角色 |
| `PUT /api/v1/roles/{id}` | 编辑名称、说明、权限及版本 |
| `DELETE /api/v1/roles/{id}` | 删除未关联账号的自定义角色 |
| `GET /api/v1/users/{id}/authorization` | 读取账号角色、范围、分组和版本 |
| `PUT /api/v1/users/{id}/authorization` | 原子修改角色及范围，立即撤权回收 |

上述管理接口仅系统管理员可用。账号创建可选择自定义角色，非管理员账号默认无分组；登录与 `/me` 返回 `roleId`、`roleName`、`permissions`、`scopeMode`、`authorizationVersion`。原 `/users/{id}/groups` 保留并切换为指定分组范围，与新入口保持一致。

迁移12新增 `platform_roles` 和 `user_authorizations`，保留原 `users.role` 的管理员/非管理员底层兼容字段，不重建账号或密码。迁移映射原管理员为全范围、原只读用户为既有分组，不替用户指定自定义角色。升级前一致性备份：`backups/pre-roles-1793864404759/platform.db`。
