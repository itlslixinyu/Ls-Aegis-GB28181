# 画面分析：按通道时间段查找

已发布正式前端，不需要重启后端。

## 行为

- 通道来源改为“通道录像”，仍支持点击、拖入单个授权通道。
- 原画面顶部的录像日期/定位时间隐藏，画面下方并排放置开始时间、结束时间及分析方式，输入内容居中；窄屏自动分行。
- 通道分析不再调用单帧分析接口。AiRangeResults.vue复用POST /ai/history-searches，明确发送一个channelIds、from、to、查找描述和verify。开始/结束时间刷新保留；查询范围须有效且不超过24小时，描述必填且最多500字。
- 本地模式verify=false，使用已有本地历史检索能力；复核模式使用本地筛查并对少量候选调用已配置大模型。上传图片仍使用现有单图千问/云端分析。
- 上方视频仅用于预览，当前视频播放位置不会替代提交的查询范围。实际录像范围由服务端历史检索任务规划。
- 右侧展示候选截图与实际时间，可取消、翻页、打开详情及定位原录像。无结果表述为已检查范围内未找到候选；预算截断明确提示覆盖不完整，不断言整段绝对没有目标。
- 保留既有权限、低算力预算、缓存及预览/录像让位；未修改录像计划或数据库结构。

## 验证

前端AI相关18项、历史检索HTTP1项通过；类型检查及Vite构建通过。正式首页和资源HTTP200。

正式浏览器用海康已有录像05:54:48—05:56:00、线索“汽车”、verify=false检索。服务端实际接收对应72秒范围和单通道，读取一个文件，返回4个相似候选；并未调用单帧分析冒充时段检查。点击05:55:05候选打开原录像并定位文件内17秒，1920×1080、无视频错误。候选是本地相似结果，不是物品存在的确定性结论。反向起止时间在页面直接拦截。

桌面1440×900开始/结束时间同一行、等宽，位于画面下方；390px宽无整页横向溢出。修复全局按钮固定高度导致候选缩略图挤出的样式：实际卡片约80px，图片约62px，完全包含在卡片内。复核录像计划与备份一致、后台继续recording。
